GASで日報を自動化してみた
（途中経過つき）

毎日の日報、書いてますか？私はずっと手書きで、「昨日と同じこと書いてるな…」と思いながら埋めていました。同じことを繰り返しているなら、自動化できるはず。そう思って、GASで日報の下書きを自動生成する仕組みを作ってみた記録です。完成形ではなく、途中経過も含めて正直に残します。

01やりたかったこと

ゴールはシンプル。毎朝、その日のカレンダー予定とTODOをまとめた日報の下書きを、自動でスプレッドシートに作っておく。あとは実績をちょい足しするだけ、という状態にしたかったんです。

  • カレンダーから「今日の予定」を自動で取得する
  • 前日の「やり残しTODO」を引き継ぐ
  • 毎朝8時に、自動でシートに行を追加しておく
memo

「全部いっぺんに作ろう」とせず、まず①のカレンダー取得だけ動かしてみたのが正解でした。

02まず動かした最小コード

いきなり完璧を目指さず、「今日の予定をログに出すだけ」から始めました。これだけで「あ、ちゃんと取れてる」と分かって安心できます。

Code.gs
// 今日の予定をログに出すだけの最小版
function logTodayEvents() {
  const cal = CalendarApp.getDefaultCalendar();
  const events = cal.getEventsForDay(new Date());
  events.forEach(e => {
    Logger.log(e.getTitle() + " / " + e.getStartTime());
  });
}

03つまずいたところ

順調…と思いきや、ちゃんとハマりました。せっかくなので失敗も残します。

① 終日予定の時刻がおかしい

終日イベントの getStartTime() がタイムゾーンの関係で前日になることがありました。AIに聞いて「終日かどうかを isAllDayEvent() で分岐する」と教わって解決。

② トリガーが動かない

毎朝の自動実行が動かない…原因は時間主導型トリガーの設定し忘れ。コードだけ書いても動かないんですね。ここは1時間溶かしました。

failure_log

「コードが正しいのに動かない」ときは、だいたいトリガーか権限。コードの外側を疑うクセがつきました。

04いまの状態と、これから

①②はクリア。毎朝、予定入りの日報下書きがシートに並ぶところまで来ました。TODOの引き継ぎ（③）はまだ未実装です。次はここをAIと一緒に作る予定。できたらまた記事にします。

未経験から始めても、「小さく動かす → つまずく → 聞く → 直す」を繰り返せば、ちゃんと前に進める。それがいちばんの収穫でした。
