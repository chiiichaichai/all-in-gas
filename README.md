# ALL-IN GAS — ゆるテック実践コミュニティサイト

佐賀発・非エンジニアのための「ゆるテック」実践型コミュニティ **ALL-IN GAS** の公式サイトです。
Claude Design で確定したデザイン（**案C「実験ノート / ベントグリッド」**）を、そのまま動く静的サイトとして実装したものです。

- コンセプト: **ゆるく使う。ちゃんと変わる。**
- ブランドカラー: Google 4色（赤・青・黄・緑）をアクセントに、ベースは温かいクリーム × 濃いチャコール
- 質感: 方眼ノート風の背景 ＋ 黒枠 ＋ ハードシャドウの「実験ノート」スタイル

## ページ構成

| ファイル | ページ | 内容 |
|---|---|---|
| `index.html` | Top | ヒーロー（コピー＋メインビジュアルのカルーセル）・ゆるテック定義・活動・記事・メンバー・参加CTA |
| `articles.html` | ゆるテック記事一覧 | 注目記事 ＋ カテゴリ色分け一覧。**カテゴリフィルタが実動** |
| `article.html` | 記事詳細 | 実験ログ構成・コピー可能なコードブロック・「おまけ情報（再現用）」パネル・目次スクロール |
| `activities.html` | 活動紹介 | オンライン／オフライン／分科会 ＋ 1ヶ月の流れ ＋ ゆるテックラジオ |
| `members.html` | メンバー紹介 | プロフィールカード ＋ 数値帯 ＋ 参加3ステップ |
| `join.html` | 参加申し込み・お問い合わせ | タブ切替・入力バリデーション・送信完了・FAQアコーディオン（すべて実動） |

全ページが相互リンクで回遊できます（Top → 記事 / 活動 / メンバー / 参加）。

## アセット

- `assets/tokens.css` — カラー・フォントの共通デザイントークン（全ページが読み込む）
- `assets/site.css` — 下層ページ共通のシェル（ナビ・フッター・ボタン・ページ見出し）
- `assets/logo.png` — ロゴ

> Top ページ（`index.html`）のみ、ヒーロー等の固有スタイルを `<style>` にインラインで持っています。

## ローカルで開く

ビルド不要の静的サイトです。`index.html` をブラウザで直接開くだけで動きます。
相対パスや一部の挙動を含めて確認したい場合は、簡易サーバ経由がおすすめです。

```bash
# このフォルダ内で
python -m http.server 8000
# → http://localhost:8000/ を開く
```

## 実装メモ / 次の差し替えポイント

- **写真はすべてプレースホルダー**（破線枠 ＋ ラベル）。実画像に差し替えれば完成します。
  - Top ヒーローのカルーセルは4枚（`main_visual` / `lecture_01` / `mokumoku` / `design_team`）。
- フォーム送信・SNS共有・ラジオ再生はデモ動作（実送信なし）。バックエンド連携時に差し替えてください。
- 記事・メンバーのデータは静的に直書きです。件数が増える前提のデザインなので、同じカード規則のまま増設できます。
- カテゴリ色: イベント・活動レポ=Red / ゆるテック実験室=Green / ライフハック=Blue / お知らせ=Yellow濃色(`#E0A500`)。

詳細なデザイン仕様は、Claude Design の `design.md`（ハンドオフ元）を参照してください。
